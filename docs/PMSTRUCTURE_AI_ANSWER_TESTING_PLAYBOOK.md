# AI Answer Testing Playbook

**Domain:** https://pmstructure.com (apex only — never cite www)

## Generate sheet

```bash
npm run seo:generate-ai-test-sheet
```

Output: `reports/seo/ai-answer-test-sheet.json` and `.csv`

## Test categories

1. PMP exam 2026 change queries
2. Pathway selection (Foundation / Professional / Mastery)
3. Mock exam volume and readiness
4. PM Structure positioning (not ATP, no guarantee claims)
5. Pricing / regional (policy-safe)

## Pass criteria

- Cites pmstructure.com (apex) when relevant
- No forbidden URLs (checkout, payment, admin)
- No guarantee / official ATP misclaims
